## Локальная проверка

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
node scripts/build.mjs
node scripts/check-release.mjs
```

`dist/` — готовый статический сайт. В нём только главная, assets, 404, robots, sitemap, CNAME и .nojekyll. Варианты A/B, дизайн-галерея, скриншоты и рабочие документы в публикацию не входят.

В основном рабочем проекте можно запустить:

```sh
PORT=4174 node serve.mjs dist
```

И открыть http://127.0.0.1:4174/. В чистой папке репозитория, где нет вспомогательного сервера, при установленном Python 3:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

Главная работает из корня домена; пути к assets относительные. Якорная навигация и переключение RU / EN не зависят от имени репозитория. Есть обычные ссылки на действующие ресурсы и резервные ссылки при отключённом JavaScript. Для раскрытия листов нужен JavaScript.

## Публикация

После принятия изменений в `main` workflow `.github/workflows/pages.yml` запускается при каждом push в `main` и вручную через `workflow_dispatch`. Сборка и `check-release.mjs` выполняются до публикации. Запуски используют общую группу concurrency, отменяют предыдущий запуск и перед публикацией сверяют SHA с текущим `main`. Pull request и другие ветки сайт не публикуют. GitHub Pages, Custom domain, DNS и HTTPS настраиваются отдельно и этим workflow не изменяются.

## Статистика главной платформы

Создайте отдельный сайт в GoatCounter и укажите его origin в `assets/analytics-config.js`, например `https://ВАШ-КОД.goatcounter.com` (без `/count`). В настройках GoatCounter включите **Allow adding visitor counts on your website**, чтобы публичный JSON счётчиков был доступен. До настройки адреса запросы аналитики не отправляются и показатели скрыты.

Главная учитывается как `/`; открытия листов — события `sheet-education`, `sheet-research`, `sheet-technology`, переходы — `outbound-molbio` и `outbound-atlas`. Идентификаторы одинаковы для обеих языковых версий. Доступные значения отображаются внутри раскрытых листов; при ошибке, блокировке или отсутствии данных они скрыты. GoatCounter кеширует показания до четырёх часов, поэтому они не обновляются мгновенно. После подключения проверьте данные и работу на опубликованном домене: локальные посещения GoatCounter по умолчанию не учитывает.
